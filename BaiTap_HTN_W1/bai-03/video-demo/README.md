# Video demo bài 03

Tải video demo bài 03 vào thư mục này với tên gợi ý:

```text
demo-bai-03.mp4
```

Video nên thể hiện quá trình build trên Ubuntu và thử lần lượt các input PA0-PA7
với các LED output PA8-PA15.

Nếu video lớn hơn giới hạn tệp của GitHub, tải lên Google Drive hoặc YouTube,
sau đó dán liên kết xem công khai vào tệp này.
